## {{< color "#800000" >}}ヴァーマイア{{< /color >}}
サレンの計画と、避けられない選択
　
### 導入：ここで何が起きるのか
フェロス、セラム、ノヴェリアのうちの２つクリアすることで、シェパードはサレンの計画に少しずつ迫り始めている。
そんな中で入るのが、サラリアン特殊部隊（STG：Special Tasks Group）からの救難信号。
向かう先は熱帯の惑星ヴァーマイア。そこにはサレンの秘密基地があるという。

{{< aside >}}<b><u>{{< color "#800000" >}}※クエストの順番{{< /color >}}</u></b>
ヴァーマイアが出た時点で行くのか、それとも、もう１つ最初に与えられたミッションをこなしてから行くのかは自由。
後回しにしたからと言ってSTGの面々が死ぬとかいったことはないため、あまり気負わず選べば良い。
……ただ、この合計４つのメインミッションの中には、「後回しにするとちょっと状況が変わる」ミッションが実は１つ、含まれている。特に結果に影響することはないのだが、かなり分かりづらい"差分"なので、気付いていないプレイヤーも多いと思われる。
{{< /aside >}}

---

### STGとの合流：敵の計画が見える
現地でキラヒー隊長 率いるSTGと合流し、基地の情報を共有する。
ここで明らかになるサレンの目的は、<b>{{< color "#008080" >}}クローガン軍団の育成{{< /color >}}</b>である。
しかもただの増兵ではなく、クローガンの出生率を下げている遺伝子兵器<b>{{< color "#008080" >}}「ジェノファージ」の治療{{< /color >}}</b>まで進めている。
　
これをシェパードは放置できない。
理由は、
■ ここで治療されたクローガンは、サレンによって洗脳された傀儡でしかない
からと、
■ 迂闊に治療すればクローガンは再び爆発的に増えてしまう
という理由もある。
合わせると、<b>{{< color "#008080" >}}爆発的な繁殖力でサレンの手下が増える{{< /color >}}</b>ことになってしまうのである。
　
しかしこの治療は当然、レックスにとっては、絶滅に瀕しているクローガン救う希望になる。
　
ここでのシェパードは、「治療させればいいじゃないか」という選択肢を持たない。
治療は阻止し、サレンの手下として洗脳されてしまったクローガンは倒し、この秘密基地は破壊する。
それしかない。
ただ、それに<b>{{< color "#008080" >}}反対するレックスにどう対処するか、という大きな選択肢{{< /color >}}</b>が発生する。

{{< spoiler >}}
レックスを説得できれば、彼は「これで増えるのは洗脳されたサレンの傀儡でしかない」という事実を受け入れて、シェパードに従ってくれる。<br>
しかし、離反しかねない<b>{{< color "red" >}}レックスを殺す{{< /color >}}</b>という選択もできる。開発が収集した統計情報では、レックスを殺したプレイヤーもけっこういたようだ。<br>
ただ、ここでレックスを殺してしまうと、後々のME2、ME3には当然出てこないし、彼の代理として出てくるキャラクターが……かなり……。<br>
一方で、<b>{{< color "#008080" >}}ここでレックスが死んでいなければ助けようのないキャラクターもいる{{< /color >}}</b>というのが、悩ましいところである。
{{< /spoiler >}}

一つの山場を乗り越えて、いよいよシェパードはキラヒーたちと協働し、サレンの追跡と施設の破壊に向かうことになる。

{{< aside >}}<b><u>{{< color "#800000" >}}※STGを援護しないと？{{< /color >}}</u></b>
ここでは、別働隊として動くサラリアン部隊を援護するかどうか選ぶ場面が３度ある。
先を急ぐのであれば無視してしまってもいいが、その場合は、厳しい戦いになるサラリアンたちに犠牲が出る。
{{< /aside >}}

　
### ソヴリンとの対話：真実が明かされる
基地内部で情報を探し、辿り着いた端末で、サレンの旗艦ソヴリンから通信が入る。
ここで判明するのは、<b>{{< color "#008080" >}}ソヴリンは宇宙船ではない{{< /color >}}</b>ということ。
内部にサレンたちが乗り込むこともできる、<b>{{< color "#008080" >}}戦艦のようなあれが機械生命体「リーパー」{{< /color >}}</b>だった。
　
彼等リーパーは、５万年ごとに銀河に現れて、そのとき繁栄している種族をすべて滅ぼすという「サイクル」を繰り返している。
そして今がその５万年目にあたり、ソヴリンはこの銀河の殲滅に動き出したのである。
リーパーが許すからおまえたちは繁栄し、そして、滅ぼすと決めたら滅びる。シェパードはソヴリンからそう宣告された。
　
### 避けられない選択
そう言われたとしても諦めるわけにはいかず、シェパードは任務を継続する。
ところがこの作戦の最終段階で、核爆弾の設置地点と対空防衛ライン、両方が同時に攻撃を受ける。
ここで、ME1で最も悪名高い(？)ニ択が発生する。

それぞれの地点で任務に当たっている二人のうち、どちらの援護に行くか。<br>
ケイダンか。<br>
アシュリーか。<br>
<b>{{< color "red" >}}助けられるのは、片方だけ{{< /color >}}</b>である。
{{< /spoiler >}}

　
### サレンとの対決
脱出直前、サレン本人と対峙する。
サレンは何を考えてリーパーに協力しているのか？　ようやくそれを本人に問うことができる。
　
サレンは、銀河を滅ぼす手助けをしているつもりはない。
抗っても滅ぼされるしかない強大な相手であれば、従うことで生き残るしかない。
つまり、彼は彼なりに、銀河を救うつもりで動いている。
―――それで本当に救われるわけがないことは、明白である。
　
シェパードは、サレンもまたリーパーに洗脳されている可能性をぶつけるが、サレンはあくまでも自分の意思であると譲らず、立ち去ってしまう。
　
### 脱出：すべてを壊して離脱
ここまででシェパードが選んだ道は、どんなものになっただろうか？
レックスを説得しただろうか？
サラリアン部隊を援護しただろうか？
そして、どちらを選んだだろうか―――？

## {{< color "#800000" >}}まとめ：ここで何が決定的になったのか{{< /color >}}
ヴァーマイアで得たものを整理すると、
■ クローガン軍団の編成を阻止した
■ リーパーの存在が確定した
■ サレンの思想が明らかになった
となる。
　
これで本当の「敵の正体」と「戦う理由」が完全に固まった。
シェパードは、評議会に結果を報告すべく、シタデルへと戻ることになる。
